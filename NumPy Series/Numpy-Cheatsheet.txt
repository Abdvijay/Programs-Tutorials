Interview Questions : 

1. What is NumPy?

    - NumPy stands for Numerical Python
    - NumPy is an open source python library.
    - Mostly used for (Numerical manipulation, Scientific computing, Machine learning, etc.)

2. Why NumPy Instead of Python Lists?

    - NumPy arrays consume less memory and execute operations much faster than Python lists.
    - Because they store homogeneous data and use optimized C implementations internally.

    ex : 
    
    1. Normal list -> lst = [1,2,3,4,5]
    2. NumPy       ->
    import numpy as np 
    arr = np.array([1,2,3,4,5])

3. What is vectorization?
