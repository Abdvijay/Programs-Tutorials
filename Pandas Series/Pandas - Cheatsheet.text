What is Pandas ?

    - Pandas is an open-source Python library used for:
    - Data Analysis
    - Data Manipulation
    - Data Cleaning
    - Reading and Writing Data

Why Pandas ?

    - Easy filtering
    - Easy Cleaning
    - Easy Analysis
    - Supports csv, json, excel.

What are the Main Data Structures in Pandas?

    - Seris - One dimensional data.
    - Data frame - tablur data.
