Matplotlib : 

# 1. Definition :

    -   Matplotlib is an open-source Python library used for creating static, animated, and interactive data visualizations.
    -   It helps convert numerical data into graphical representations.

# 2. Why do we use Matplotlib ?

    Data Visualization
    Trend Analysis
    Comparing Data
    Finding Patterns
    Presenting Reports
    Machine Learning Result Visualization

# 3. Why is Visualization Important?

    -   Visualization is the graphical representation of data.
    -   Instead of reading thousands of numbers, graphs make information easier to understand.

# 4. pyplot module ?

    -   matplotlib.pyplot contains functions to create and customize different types of graphs such as 
        line, bar, pie, scatter, and histogram.

# 5. Figure - A Figure is the top-level container that holds all the plots.

# 6. Axes - Axes represent the area where graphs are plotted inside a Figure.

# 7. plt.legend() - To identify multiple datasets displayed on the same graph.

# 8. plt.grid() - To improve graph readability by adding reference lines.

# 9. plt.savefig() - To save the generated plot as an image file for reports or presentations.

# 10. plt.show() - It renders and displays the graph on the screen.
